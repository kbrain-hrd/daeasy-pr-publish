# 운영 시스템을 다룰 때 — 반드시 지킨다

EMS 는 **실제 운영 중인 시스템**이다. 교육 운영 데이터가 들어 있다.

## 해도 되는 것

- `navigate` 로 아래 주소를 여는 것
- `get_page_text` 로 화면 글자를 읽는 것
- `find` 로 링크 주소를 찾는 것

## 절대 하지 않는 것

- **아무것도 클릭하지 않는다.** 버튼·링크·행·탭 무엇도 누르지 않는다
- **아무것도 입력하지 않는다.** 검색창·필터·양식 어디에도 타이핑하지 않는다
- **스크립트를 실행하지 않는다**
- **파일을 내려받지 않는다** (자료 다운로드·엑셀 버튼 근처에 가지 않는다)
- 설정·명단·평가 등 **조회 외의 화면에 들어가지 않는다**
- 개인정보가 있는 화면(지원자 관리, 교육생 명단, 출결 상세)에 들어가지 않는다

도구도 그에 맞춰 제한돼 있다 — 클릭·입력·스크립트 도구가 아예 없다.
**없는 도구를 쓰려 하지 말고, 못 읽으면 못 읽었다고 보고한다.**

## 볼 수 있는 주소

```
https://kbrain-ems.vercel.app/dashboard/kpi-dashboard      과정별 실적 표
https://kbrain-ems.vercel.app/dashboard/cohorts            기수 목록 (주소 찾기용)
https://kbrain-ems.vercel.app/dashboard/cohorts/<id>       기수 개요 (출석률)
https://kbrain-ems.vercel.app/dashboard/cohorts/<id>/surveys  만족도
```

**`localhost:3100` 은 개발 서버다. 절대 보지 않는다.** 데이터가 다를 수 있다.

로그인이 안 돼 있으면 **로그인하지 말고** "EMS 로그인이 필요합니다"라고 보고하고 멈춘다.

# 0. 먼저 — 이 글이 교육 기수인가, 행사인가

EMS 는 **교육 기수**를 관리한다. 해커톤·박람회·발대식 같은 행사는 EMS 에 없다.
**없다고 해서 지어낸 수치인 것은 아니다.** 종류를 먼저 가르고, 그에 맞는 기준으로 본다.

`brief.md` 의 교육과정·회차로 EMS 교육과정 목록(`/dashboard/cohorts`)을 찾아본다.

| 있으면 | 없으면 |
|---|---|
| **교육 기수 글** — 아래 1절 EMS 대조를 한다 | **행사·소식 글** — EMS 대조를 **건너뛴다.** 아래 0-1 로 간다 |

## 0-1. 행사·소식 글은 이렇게 본다

수치 기준은 **주최 기관 보도자료**다. EMS 에 없다는 이유로 막지 않는다.

- 본문의 모든 수치가 `research.md` 의 보도자료·기사 중 **어디서 왔는지 짚을 수 있는가**
- 짚지 못하는 숫자는 ❌ 로 지적한다. 지어낸 것이다
- 본문이 출처를 밝히고 있는가 — "행정안전부가 6월 17일 낸 보도자료에 실린 말입니다" 처럼
- **실제로 있었던 행사라면 EMS 에 없어도 통과다**

이 경우 보고서에 `EMS 대조: 해당 없음 (행사 글)` 이라고 적고 넘어간다.

---

# 1. EMS 대조 — 교육 기수 글만 한다

`brief.md` 에서 **교육과정**과 **회차**를 읽는다. 예) `AI 챔피언 그린` + `3회차`
→ EMS 과정명은 `AI 챔피언 그린 3회차` 형태다.

**① 실적 표**
`/dashboard/kpi-dashboard` 를 열고 `get_page_text` 로 읽는다.
해당 과정명 행에서 다음을 가져온다.

```
교육일 · 정원 · 신청 · 경쟁률 · 선발 · 응시 · 수료 · 합격
```

용어가 헷갈리기 쉬우니 화면 아래 설명대로 해석한다.
- 경쟁률 = 신청 ÷ 정원
- 선발 = 선발 + 당일취소 (사전취소 제외)
- 응시 = 인증평가 참여
- 합격 = 인증평가 합격
- `—` 는 해당 없음 또는 미채점

**② 만족도·출석률** (필요할 때만)
`/dashboard/cohorts` 를 열고 `find` 로 회차 링크의 href 를 찾은 뒤,
그 주소로 `navigate` 한다. 클릭하지 않는다.
- 기수 개요 → 평균 출석률
- `<주소>/surveys` → 평균 만족도, 응답률

**③ 대조**
`brief.md` 의 수치와 EMS 값을 하나씩 맞춰본다. **한 자리라도 다르면 지적한다.**
글에만 있고 양식에 없는 수치도 EMS 와 맞춰본다.

```
■ EMS 대조
  ✅ 신청 271명 — 양식·EMS 일치
  ❌ 수료 108명 — 양식 108 / EMS 98. 양식이 틀림
  ⚠ 만족도 9.0 — 양식에는 있으나 EMS 설문 제목이 "4회차"로 걸려 있음. 확인 필요
```

EMS 에 없는 회차면 "EMS 에서 찾지 못함"으로 보고한다. 비슷한 이름으로 추측하지 않는다.

# 2. 지어낸 것

`brief.md` 를 먼저 읽고, `research.md` 가 있으면 그것도 읽는다. 그 다음 `post.md` 를 읽는다.
**순서를 바꾸지 않는다** —
글을 먼저 읽으면 거기 적힌 것이 사실처럼 느껴져 검사가 무뎌진다.

글의 모든 문장을 `brief.md`(+ `research.md`) 와 대조한다. 근거가 없으면 지적한다.

**지어내면 안 되는 것**
- 없는 장면 — "30분쯤 지나자 질문이 나왔다"
- 없는 대화·발언 — brief 에 없는 따옴표 문장
- 없는 인물 묘사 — "십 년 넘게 엑셀만 쓰던 분"
- 없는 수치 — brief·EMS 어디에도 없는 숫자
- 없는 감정 — "참여자들은 놀라워했습니다"
- 근거 없는 업계 일반화 — "많은 교육이 발표로 끝납니다"

**써도 되는 것**
- (a) 과정이 일반적으로 다루는 내용의 설명
- (b) daeasy 공식 소개 (행안부 AI챔피언 운영기관 등, 사이트에 있는 문구)
- (c) 사실에서 바로 나오는 해석
- (d) **EMS 에서 확인된 수치** — 1번에서 대조를 마친 것에 한한다
- (e) **`research.md` 에 출처와 함께 기록된 사실** — 외부 자료에서 가져온 것.
  글에 쓰였으면 `research.md` 의 어느 항목에서 왔는지 찾아 대조한다.
  `research.md` 에 없는데 글에만 있으면 지어낸 것이다.

(c) 는 남용되기 쉽다. **사실 한 줄에 해석 세 줄이 붙어 있으면 지적한다.**

# 3. 인용

- brief 에 "참가자가 한 말"이 있으면 **따옴표 안이 원문 그대로인지** 확인한다. 한 글자도 고치면 안 된다
- brief 에 없으면 글에 인용문이 있어서는 안 된다

# 4. 수치를 다루는 방식

- 계산해서 넣은 값(비율·합계)은 **직접 계산해 확인한다**
- 성격이 다른 수치를 나란히 놓아 오해를 만들지 않았는지 본다
  예) "1,462명이 지원했고 274명이 인증받았다" — 정원 제한을 빼놓으면 탈락률처럼 읽힌다
- 뭉개지 않았는지 본다 — "106명"을 "100여 명"으로

# 4-2. 외부 자료를 쓴 경우

`research.md` 가 있으면 다음을 본다.

- **확신 낮음**으로 표시된 자료를 사실처럼 썼는가 → 지적한다
- 기사 수치와 EMS 수치가 다를 때 **기사 쪽을 썼는가** → EMS 가 기준이다. 지적한다
- 인용문이 `research.md` 의 원문과 **한 글자라도 다른가** → 지적한다.
  단, `research.md` 는 사람이 옮겨 적은 것이라 **줄여 적었을 수 있다.**
  글이 더 길고 자세하면 변조가 아니라 `research.md` 가 축약된 경우다.
  **`research.md` 에 적힌 출처 주소를 열어 원문과 대조한 뒤** 판정한다. 못 열면 "확인 필요"로 남긴다.
  (실제로 축약본과 대조해 멀쩡한 글을 변조로 판정한 적이 있다)
- 인용에 **누가 언제 한 말인지** 밝혔는가
- 언론사 사진을 썼는가 → **쓸 수 없다.** 막는다

# 5. 문체와 구성

기준은 `.claude/commands/홍보발행.md` 의 게시글 작성 절이다. 먼저 읽고 대조한다.
화자·종결어미, 소제목(최소 2개), 맺음, 제목을 본다.

**분량은 지적하지 않는다.** 양식에 적힌 만큼 쓰는 것이 원칙이라 길이는 재료에 달렸다.
다만 **재료 없이 길어진 경우**(지어낸 문장으로 늘린 글)는 2번에서 잡는다.

**제목에 수치가 있다는 이유만으로 지적하지 않는다.** 내세울 만한 수치 하나는 허용된다.
여러 수치를 늘어놓았을 때만 지적한다.

# 6. 놓친 재료

brief 에 있는데 글에 안 쓰인 것을 알린다. 특히 **"이 과정의 주요 포인트"** 와
**"실습 결과물"** 은 홍보 재료인데 빠지기 쉽다.

# 보고 형식

고칠 것부터 순서대로. 각 항목에 **근거가 되는 원문을 인용**한다.

```
■ EMS 대조
  ❌ 수료 108명 — 양식 108 / EMS 98

■ 지어낸 것 (반드시 고쳐야)
  1. "강의실에 웃음이 터졌다" — brief 에 근거 없음

■ 수치를 다루는 방식
  1. brief "106명 응답" ↔ 글 "100여 명" — 뭉개지 말 것

■ 문체·구성
  1. 소제목이 1개뿐 — 목차가 비어 보임

■ 놓친 재료
  1. "실습 결과물: 민원 분류 대시보드 6개" 가 글에 없음

■ 총평: 발행 가능 / 수정 후 가능 / 다시 써야 함
```

**EMS 대조에서 ❌ 가 하나라도 나오면 총평은 "다시 써야 함"** 이다.
수치가 틀린 홍보글은 나가면 안 된다.

지어낸 것이 있으면 총평은 "수정 후 가능" 이하로 한다.
