# Liner Scholar 프로젝트 문헌

`scholar.liner.com` 프로젝트 867520 에 모아 둔 문헌을 주제별로 묶었다.
**우리 루브릭에 실제로 쓴 것**은 `docs/루브릭-근거.md` 에 자세히 적었고,
여기는 전체 지도다 — 기준을 고칠 때 어디를 볼지 찾기 위한 것이다.

채점 기준과 무관해 프로젝트에서 뺀 3편 — *Can Good Writing Be Generative* ·
*It was 80% me, 20% AI* · *Co-Writing with AI, on Human Terms*.

## 1. 품질 평가 — 무엇이 좋은 글인가

| 문헌 | 무슨 내용 | 우리와의 관계 |
|---|---|---|
| **A large-scale comparison of human vs ChatGPT essays** (Herbold, Sci Reports 2023) | ChatGPT 에세이가 인간보다 품질 평점 높음. AI 글은 어휘 다양성 크고 담론·인식 표지 적음 | **씀** — 문체 지표 방향을 뒤집었다 |
| **Art or Artifice?** (Chakrabarty, CHI 2024) | TTCW 창의성 검사에서 LLM 이 전문가보다 3~10배 적게 통과. LLM 평가자는 전문가와 상관 없음 | **씀** — 대체 불가능성 최상위 근거 |
| **The Pure Poet** (Gunser, In2Writing 2022) | 독자는 AI 글을 구별 못 하면서 확신했다. AI 글은 덜 매력적으로 평가됨 | **씀** — 매끄러움 ≠ 읽을 값어치 |
| **AI-Slop to AI-Polish** (Chakrabarty 2025) | 최고 LLM 도 품질 판단이 무작위 수준. 전문가는 한 편에 평균 8곳 수정 | **씀** — 채점 방식·고쳐쓰기 유형 |
| **Repairing the Cracked Foundation** (Gehrmann, JAIR 2023) | 20년치 NLG 평가 결함 정리. 모범 관행이 27%만 지켜짐 | **씀** — 지표를 문서에 고정하는 규칙 |
| **Is This Abstract Generated by AI?** (Ma 2023) | AI 텍스트는 정확하나 깊이 부족. **언어 중복과 사실 오류가 더 많다** | **씀** — 차단 검사(수치·인용)와 중복 점검 |
| **On the creativity of large language models** (Franceschelli, AI & Society 2023) | Boden 의 창의성 이론(가치·새로움·놀라움)과 4P 로 LLM 창의성 분석 | **씀** — 대체 불가능성의 이론적 뼈대 |
| **LitBench** (Fein 2025) | 창작 평가 최초 표준 벤치마크. 훈련된 보상 모델 78% (제로샷보다 높음) | 미사용 — 채점 자동화할 때 |
| **A Confederacy of Models** (Gómez-Rodríguez, EMNLP 2023) | 최신 LLM 다수 비교. 대부분 인간보다 열위, 유머는 특히 | 미사용 |
| **Detection of AI-generated Essays** (Yan) | AI 에세이 탐지 95% 이상 | 미사용 — 탐지가 목적이 아니다 |
| **Can AI-Generated Text be Reliably Detected?** (Sadasivan 2023) | 패러프레이즈 공격에 탐지기 무력. 이론적으로 탐지 불가능에 수렴 | 참고 — 탐지에 기대지 않는 이유 |
| **Ghostbuster** (Verma, NAACL 2024) | 블랙박스 모델 텍스트 탐지, F1 99.0 | 미사용 |
| **A Watermark for LLMs** (Kirchenbauer 2023) | 생성 시점에 통계적 워터마크 삽입 | 미사용 |

## 2. 사람과 AI 의 협업 — 주도권·진정성

| 문헌 | 무슨 내용 | 우리와의 관계 |
|---|---|---|
| **Wordcraft** (Yuan, IUI 2022) | 작가·LLM 공동 집필 에디터. 프롬프트 미세 변화가 결과를 크게 흔든다 | **씀** — 채점이 필요한 이유 |
| **Creative Writing with an AI Assistant** (Ippolito 2022) | 전문 작가 13명. 브레인스토밍엔 유용하나 작가의 목소리·스타일 보존에 근본 한계 | 참고 — 문체 배점을 낮춘 방향과 일치 |
| **How Does the Disclosure of AI Assistance Affect Perceptions?** (Li 2024) | AI 보조를 공개하면 평균 품질 평점 하락, 편차 증가 | 미사용 — 공개 정책 정할 때 |
| **The Value, Benefits, and Concerns** (Li, CHI 2024) | AI 보조에 긍정적이나 직접 생성은 책임감 저하·다양성 감소 위험 | 참고 — 동질화 우려와 이어짐 |
| **Large Language Model in Creative Work** (Chen & Chan, Mgmt Sci 2024) | **대필자로 쓰면 전문가에게 해롭고, 조언자로 쓰면 비전문가가 전문가 수준 근접** | 미사용 — 눈여겨볼 것 |
| **From Tool to Companion** (Biermann, DIS 2022) | 작가 20명. 협업 장벽 — 감정적 가치 우선, 자신감, 제어 부족 | 미사용 |
| **How Novelists Use Generative LMs** (Calderwood 2020) | 소설가 4명. 아이디어 생성·적대적 제안·제약 도구로 활용 | 미사용 |
| **A Thematic Framework for Human-AI Co-creative Writing** (Rafner 2025) | 작가 경험 5테마 — 효율·능력·좌절·자기반성·소유권 | 미사용 |
| **ChatGPT-3.5 as writing assistance** (Bašić 2023) | ChatGPT 보조군이 유의미하게 낫지 않았다. 미숙한 사용자엔 혼란 | 참고 — 도구가 자동으로 좋게 하지 않는다 |
| **Exploring AI-Generated Text in Student Writing** (Woo 2023) | AI 텍스트가 품질 향상. 숙련·미숙 모두에 효과 | 미사용 |
| **Amazement and Trepidation** (Anson 2022) | 과정 없이 완성문을 얻는 상황에 교육자 대응 필요 | 미사용 |
| **Unmet Creativity Support Needs** (Kreminski 2022) | 창작자가 필요로 하는 지원과 현 시스템의 격차 | 미사용 |
| **CoAuthor** (Lee, CHI 2022) | GPT-3 와 작가 63명의 1,445개 세션 데이터셋 | 미사용 |

## 3. 시스템 설계 — 어떻게 만들 것인가

| 문헌 | 무슨 내용 | 우리와의 관계 |
|---|---|---|
| **Weaver** (Wang 2024) | 글쓰기 특화 LLM. 도메인 사전학습으로 GPT-4 능가 | **씀** — 좋은 예시를 규격에 명시하는 근거 |
| **Pearl** (Mysore 2023) | 사용자 과거 문서를 검색해 프롬프트 보강 | **씀** — 과거 자료로 채우는 구조(④ 정보수집) |
| **Agents' Room** (Huot 2024) | 서사 이론대로 하위 작업 분해, 전문 에이전트 협업 | **씀** — 역할 분리(정보수집·글검수·발행검수) |
| **Catch Me If You Can? Not Yet** (Wang 2025) | 작가 400명 4만 편. **구조화된 포맷은 문체 모방 가능, 블로그·포럼은 근본 한계** | **씀** — 구조화된 포맷이 유리하다는 근거 |
| **AI-assisted academic writing: ethical use** (Cheng 2025) | 표절·환각·부정확 인용 문제와 투명성 가이드라인 | **씀** — 차단 검사 세 항목의 대응 |

| **Quality-Diversity through AI Feedback** (Bradley 2023) | QDAIF — 품질과 다양성 동시 개선 | 미사용 |
| **Steering LLMs to Evaluate Creativity** (Olson 2024) | 모델 내부 '지루함/창의' 축을 뽑아 추론 시 증폭 | 미사용 |
| **GhostWriter** (Yeh 2024) | 사용자 문체를 암묵적으로 학습, 스타일 제어 제공 | 미사용 |
| **Small LMs can Outperform Humans** (Marco 2024) | 미세조정 BART-large 가 창작 단편에서 인간보다 14% 높은 점수 | 미사용 |
| **Pron vs Prompt** (Marco 2024) | 수상 소설가 vs GPT-4. 인간이 제목 줄 때 향상 | 미사용 |
| **Viewpoint: AI as Author** (Heerden 2021) | AI 글쓰기의 문학성 연구 부재. 평가에 문학 이론 필요 | 미사용 |
| **Automatic Authorship Analysis** (Richburg 2024) | 협업 텍스트 저자 판별. n-gram 이 더 견고 | 미사용 |
| **The automated writing assistance landscape** (Dale 2021) | 자동 글쓰기 보조 60년사 | 미사용 |
| **What Can't LLMs Do?** (Fok & Weld) | LLM 이 못 하는 것을 물으며 도구 설계 논의 | 미사용 |
| **The Future of AI-Assisted Writing** (Pereira 2023) | Pull 대 Push 패러다임 비교 | 미사용 — 도구 사용성이라 해당 없음 |

## 4. 아직 안 썼지만 눈여겨볼 것

- **Large Language Model in Creative Work** (Chen & Chan) — LLM 을 대필자로 쓸 때와
  조언자로 쓸 때 결과가 갈린다. 우리 워크플로우는 대필에 가까운데, 조언자 쪽으로
  옮길 여지가 있는지 볼 만하다.
- **How Does the Disclosure of AI Assistance Affect Perceptions?** (Li 2024) —
  AI 사용을 밝히면 평점이 떨어진다. 공개 정책을 정할 때 필요하다.
- **LitBench** (Fein 2025) — 훈련된 보상 모델이 제로샷 평가자보다 정확했다.
  우리 채점을 자동화하려면 여기를 본다.
