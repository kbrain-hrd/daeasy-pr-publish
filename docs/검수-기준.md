# 검수 기준 — 1차·2차에서 무엇을 보는가

`/홍보발행` 의 6단계를 풀어 쓴 문서다. **무엇을 기준으로 막고 통과시키는지**와
**그 기준이 어느 논문에서 왔는지**를 한자리에 모았다.
절차 자체는 `.claude/commands/홍보발행.md` 6절이 정본이고, 여기는 그 근거와 읽는 법이다.

---

## 워크플로우에서의 위치

```
4. 정보수집 ─┐
             ├─ 동시에 진행. 재료가 모여야 글이 써진다
5. 게시글 작성 ┘
        │
        ▼
6-1  1차 검수 — 루브릭 채점       "이 글이 값어치가 있나"
        │  12점 미만 ─────────────▶ 5단계로 되돌림 (최대 3회)
        │  12점 이상
        ▼
6-2  2차 검수 ① 글검수            "쓴 것이 사실인가"
        │
        ▼
6-3  2차 검수 ② 발행검수          "1차를 믿지 않고 다시 본다" — 최종 승인
        │
        ▼
7. 네이버 발행 → 8. 사이트 반영
```

**1차는 글의 값어치를 재고, 2차는 사실을 대조한다.** 순서를 바꾸지 않는다.
사실이 틀린 글을 다듬어 봐야 소용없고, 값어치 없는 글을 사실 대조해 봐야 소용없다.

---

## 6-1. 1차 검수 — 루브릭 채점

```
uv run python scripts/score.py out/{slug}
```

네 가지를 본다. 앞의 세 개는 코드가 세고, 마지막 하나는 사람이 매긴다.

### ① 차단 검사 — 하나라도 걸리면 발행하지 않는다

점수와 무관하다. 걸리면 그 자리에서 멈춘다.

| 검사 | 걸리는 조건 |
|---|---|
| 발견 한 줄 | `insight.md` 가 없다 |
| **지어낸 숫자** | 본문 숫자가 `brief.md`·`research.md` 어디에도 없다 (날짜는 표기가 갈려 제외) |
| **지어낸 인용** | 따옴표 안 문장이 원자료에 그대로 없다 |
| 사진 자리 | `[사진]` 자리가 실제 파일 수보다 많다 |
| 사진 중복 | 같은 파일을 두 번 깔았다 |
| 제목 | 60자 초과 |

숫자와 인용을 차단 검사에 둔 이유는 **AI 글의 실제 결함이 문체가 아니라 사실 오류와
중복**이기 때문이다 (Ma 2023). 점수로 깎을 게 아니라 아예 막아야 하는 항목이다.

### ② 검색 노출 — 5.0 만점

| 배점 | 항목 |
|---|---|
| 1.0 | 제목 앞 절반에 기관·과정명 |
| 1.0 | 첫 문단에 기관·과정·행위가 다 들어감 |
| 1.0 | 태그 12~16개 + 다섯 묶음 |
| 0.5 | 소제목이 검색어를 품음 |
| 0.5 | 본문 1,500자 이상 |
| 0.5 | 사진 2장 이상 |
| 0.5 | 사이트로 가는 링크 |

이 점수는 아래 7항목의 **4번으로 환산**된다 (4.0↑=2 / 2.5~3.5=1 / 2.0↓=0).

### ③ 문체 지표 — 참고용, 점수가 아니다

문장 수·평균 길이·어휘 다양성·문단당 문장·상투어·헤징을 센다.
**어휘 다양성은 높다고 좋은 게 아니다** — AI 글이 오히려 사람보다 높다 (Herbold 2023,
실측도 사람 0.755~0.812 / 우리 글 0.832~0.874). 그래서 방향을 정하지 않고 표시만 한다.

경고로 올리는 것은 검증된 두 가지뿐이다.

- **상투어·헤징** — 나오면 7항목 5번에서 깎인다
- **문단당 평균 2.2문장 미만** — 문장마다 줄을 바꿔 여백이 벌어진 글. 사이트 기존 글이 2.92였다

담론표지·명사화는 사람 글에서도 0에 가까워 변별력이 없었다. 세기는 하되 경고하지 않는다
(검증 안 된 지표를 기준으로 쓰지 말라 — Gehrmann 2023).

### ④ 7항목 채점 — 14점 만점, 12점 이상 통과

**코드가 못 센다. 사람이 표를 채운다.** 각 항목 0·1·2점.

| # | 항목 | 2점 | 0점 |
|---|---|---|---|
| 1 | **대체 불가능성** | 이 회차만의 사실 3개 이상 | 기관명만 바꿔도 성립 |
| 2 | **출처 추적성** | 모든 문장 출처를 짚음 | 못 짚는 문장 3개 이상 |
| 3 | **현장 증거** | 실습 장면·반응·산출물이 문단마다 | 일반론뿐 |
| 4 | **검색 노출** | 위 점수 4.0 이상 | 2.0 이하 |
| 5 | **사람 문체** | 상투어·헤징 0, 꾸민 문장 없음 | 여러 곳 |
| 6 | **군더더기 없음** | 뺄 문단 없음 | 두 곳 이상 |
| 7 | **구성** | 맥락→무엇을→무엇이 남았나 | 흐트러짐 |

**되돌리는 조건** — 셋 중 하나면 5단계로 간다. 최대 3회.

- 차단 검사에 걸림
- **1번이 0점** — 합계와 무관하게 재작성. 대체 불가능성이 없으면 쓸 이유가 없는 글이다
- 합계 11점 이하

고칠 때 **전체를 다시 쓰지 않고 깎인 항목만 손본다.** 전문가는 한 편에 평균 8군데를
고쳤고 유형이 정해져 있었다 — 진부한 표현 · 중복 · 맥락 없는 서술 · 과하게 꾸민 문장 ·
지나치게 매끄러운 톤 (AI-Slop to AI-Polish 2025). 이 다섯을 먼저 본다.

**분량을 늘려 4번을 올리지 않는다.** 5번·6번이 함께 깎여 손해다.

3회를 돌려도 12점에 못 미치면 **멈추고 보고한다.** 억지로 통과시키지 않는다.

### 검색 노출

- **네이버 C-Rank / D.I.A+** (네이버 공식) — 문서가 아니라 **출처(블로그)의 신뢰도**를 보고,
  검색 의도 부합과 "경험에 의한 글"을 따진다. 등급 C 라 확정 사실로 쓰지 않는다.
- 본문 2,000자·체류 2분 30초 같은 수치는 **업계 관찰이고 검증되지 않았다.**
  그래서 우리 기준은 1,500자로 낮춰 잡고 배점도 0.5 로 뒀다.

## 6-2·6-3. 2차 검수 — 사실을 대조한다

1차를 통과한 글만 온다. **여기서는 점수를 매기지 않는다. 사실만 본다.**

### 6-2. `글검수` — 원자료·EMS 와 대조

- `brief.md`·`research.md` 와 `post.md` 를 대조해 **근거 없는 문장**을 찾는다
- 원자료를 먼저 읽고 글을 나중에 읽는다. 순서를 바꾸면 글에 적힌 것이 사실처럼 느껴져 검사가 무뎌진다
- **읽기만 한다.** EMS 에서 클릭·입력·다운로드를 하지 않는다 (도구도 그렇게 제한돼 있다)

수치 기준이 글의 종류에 따라 갈린다.

| 글의 종류 | 수치 기준 | EMS 대조 |
|---|---|---|
| **교육 기수** — EMS 에 기수가 있는 건 | **EMS 가 기준.** 기사 숫자가 달라도 EMS 를 쓴다 | 한다. ❌ 하나면 되돌린다 |
| **행사·소식** — 해커톤·박람회·발대식 등 | **주최 기관 보도자료가 기준** | **건너뛴다** |

**EMS 에 없다는 이유로 막지 않는다.** EMS 는 교육 기수를 관리하는 시스템이라
행사는 애초에 들어 있지 않고, 다른 팀이 진행한 교육도 빠져 있을 수 있다.
실제로 진행된 건이면 통과다. 대신 행사 글은 **모든 숫자의 출처를 `research.md` 에서
짚을 수 있어야 하고**, 짚지 못하는 숫자는 뺀다.

지어낸 것으로 보는 것 — 없는 장면 · 없는 대화 · 없는 인물 묘사 · 없는 수치 · 없는 감정 ·
근거 없는 업계 일반화.

### 6-3. `발행검수` — 최종 승인

**1차 결과를 믿지 않는다.** 1차가 통과시킨 항목도 원자료와 다시 대조한다.
1차 보고서를 넘기지 않는 이유는 그것을 먼저 읽으면 같은 판단을 반복하게 되기 때문이다.

2차가 막으면 **발행하지 않는다.** 고쳐서 다시 돌린다.
두 검수 결과를 사용자에게 보여주고 확인받은 뒤에만 7단계로 넘어간다.

## 왜 세 번 보는가

LLM 을 심판으로 쓰면 편향이 붙는다 — 위치 편향 40%, 장황한 답을 선호 15%,
자기가 쓴 글을 선호 5~25%. 게다가 최고 모델도 글 품질 판단이 무작위 수준이다
(AI-Slop to AI-Polish). **그래서 코드가 셀 수 있는 것만 코드에 맡기고,
판단은 사람이 하며, 사실 대조는 서로 모르는 두 검수자가 따로 한다.**
